# Methods

This document describes the full computational pipeline used to dock a polyamide dimer ligand (`PA2_opt`) into the active site of NylC (6-aminohexanoate-oligomer hydrolase, PDB: [3AXG](https://www.rcsb.org/structure/3AXG)), and to test whether the enzyme's native tetrameric assembly changes the docking outcome relative to an isolated monomer.

## 1. Software

| Tool | Version | Purpose |
|---|---|---|
| AutoDock Vina | 1.2.7 | Docking engine; `vina_split` (bundled) used for pose extraction |
| MGLTools / AutoDockTools | 1.5.7 | Receptor and ligand PDBQT preparation |
| Open Babel | 3.1.1 | SDF → PDB format conversion (ligand input only) |
| PyMOL | — | Structure inspection, chain extraction, geometric analysis |

All work was performed on Windows (Command Prompt).

> **Note:** Open Babel's PDBQT output plugin was non-functional on this installation (`obabel -L formats` did not list `pdbqt`, and setting `BABEL_LIBDIR`/`BABEL_DATADIR` did not resolve it). Open Babel was therefore used only for the SDF→PDB conversion step; final PDBQT generation for both receptor and ligand was done with MGLTools, which produced consistent atom typing and Gasteiger charges across both molecules.

## 2. Receptor preparation

### 2.1 Structure retrieval

The asymmetric unit of 3AXG contains 15 chains (A–O), all identical 355-residue copies of the NylC precursor sequence. `REMARK 350` in the PDB file specifies that chains **A, B, C, D** constitute one complete biological tetramer with no symmetry operation required.
curl -o data/raw/3AXG.pdb https://files.rcsb.org/download/3AXG.pdb

### 2.2 Chain extraction

Two receptor variants were prepared from the same downloaded file, via `scripts/prepare_receptor.pml` and `scripts/prepare_tetramer_receptor.pml` respectively:

**Monomer (chain A only):**
```python
# PyMOL — scripts/prepare_receptor.pml
remove not chain A
remove solvent
remove resn NA
save data/processed/3AXG_chainA.pdb
```

**Tetramer (chains A–D):**
```python
# PyMOL — scripts/prepare_tetramer_receptor.pml
remove not chain A+B+C+D
remove solvent
remove resn NA
save data/processed/3AXG_tetramer.pdb
```

`resn NA` (crystallographic sodium ions from the crystallization buffer) was removed from both; these ions are not associated with the active site.

**Chain-break note:** `REMARK 465` in the source PDB lists residues 261–266 as unresolved in most chains — the disordered remnant of NylC's autoproteolytic self-cleavage site. The catalytic residue, Thr-267 (the new N-terminus generated by this cleavage), is fully resolved in all chains used. `prepare_receptor4.py` handled the resulting backbone discontinuity without error.

### 2.3 Protonation and PDBQT conversion

Automated via `scripts/prepare_receptor.py monomer` / `scripts/prepare_receptor.py tetramer`, which wrap:

prepare_receptor4.py -r 3AXG_chainA.pdb -o 3AXG_chainA.pdbqt -A hydrogens -U nphs_lps_waters
prepare_receptor4.py -r 3AXG_tetramer.pdb -o 3AXG_tetramer.pdbqt -A hydrogens -U nphs_lps_waters


- `-A hydrogens` — adds hydrogens and Gasteiger partial charges. Protonation states are assigned using standard residue-type defaults (not a pKa-prediction algorithm such as PROPKA); this is a known simplification, flagged here as a candidate refinement if active-site electrostatics prove sensitive to a specific His/Asp/Glu tautomer.
- `-U nphs_lps_waters` — merges nonpolar hydrogens into their parent heavy atom, removes lone pairs, and strips any remaining waters.

The crystallization buffer was pH 8.0 (HEPES); this was used as the working protonation reference in the absence of a specific target reaction pH.

## 3. Ligand preparation

The ligand, `PA2_opt` (a linear polyamide dimer, ~40 atoms, one internal hydrolyzable amide bond), was supplied as a 3D `.pdb` file (`data/raw/PA2_opt.pdb`).

> **Note:** an initial attempt was made to convert the ligand from SDF using Open Babel, but its PDBQT output plugin was non-functional on this installation (`obabel -L formats` did not list `pdbqt`, and setting `BABEL_LIBDIR`/`BABEL_DATADIR` did not resolve it). The already-available PDB version of the ligand was used directly instead, bypassing Open Babel entirely.

PDBQT conversion is automated via `scripts/prepare_ligand.py`, which wraps: 
prepare_ligand4.py -l PA2_opt.pdb -o PA2_opt.pdbqt -A hydrogens


`prepare_ligand4.py` builds the rotatable-bond torsion tree used by Vina's flexible-ligand search. The resulting PDBQT reported **13 active torsions**. The internal amide C–N bond was confirmed not to be flagged as rotatable, consistent with its partial double-bond (resonance) character.

## 4. Binding-site (grid box) definition

The grid box was centered on the pocket surrounding the catalytic residue, **Thr-267 (chain A)**, identified from the paper describing 3AXG's autoprocessing mechanism. (see README for paper's reference)

```python
# PyMOL
select pocket, byres (chain A and resi 267 around 4)
select pocket, pocket or (chain A and resi 267 and resn THR)
print(cmd.centerofmass("pocket and name CA"))
```

This selects all residues with any atom within 4 Å of Thr-267, explicitly includes Thr-267 itself (excluded by default by the `around` operator), and returns the centroid of their Cα atoms as the box center.

Box size was estimated from the ligand's extended conformational length (chemistry-based estimate, ~17–20 Å for a 2-unit -NH-(CH₂)₅-CO- chain in an all-*trans* conformation) plus an ~8–10 Å search buffer, since the ligand's as-supplied conformation (`cmd.get_extent`) measured only ~14.5 × 5.4 × 4.6 Å — shorter than the extended estimate, indicating a coiled starting geometry that Vina's torsional search would need room to unfold from.

**Center and size used for both monomer and tetramer runs** (identical, since chain A's coordinates are unchanged by the presence or absence of chains B–D):

center_x = 36.821 size_x = 25
center_y = 70.964 size_y = 25
center_z = 108.391 size_z = 25


## 5. Docking runs

`config/monomer_vina_config.txt` / `config/tetramer_vina_config.txt` (identical apart from the `receptor` field):

receptor = 3AXG_chainA.pdbqt # or 3AXG_tetramer.pdbqt
ligand = PA2_opt.pdbqt
center_x = 36.821
center_y = 70.964
center_z = 108.391
size_x = 25
size_y = 25
size_z = 25
exhaustiveness = 24
num_modes = 9
energy_range = 4


Run via `scripts/run_docking.py monomer` / `scripts/run_docking.py tetramer`, which wrap:

vina.exe --config monomer_vina_config.txt --out monomer_out.pdbqt --verbosity 2 > monomer_log.txt
vina.exe --config tetramer_vina_config.txt --out tetramer_out.pdbqt --verbosity 2 > tetramer_log.txt


`exhaustiveness` was raised from Vina's default (8) to **24**, a 3× increase, given the ligand's relatively high torsion count (13); more rotatable bonds expand the conformational search space substantially, and the default is calibrated for more typical, less flexible small-molecule ligands.

### 5.1 Replicate runs

To distinguish a genuine monomer-vs-tetramer score difference from ordinary run-to-run stochastic variation (Vina's search is seed-dependent), each condition was repeated **5 times** with explicit seeds, via `scripts/run_replicates.py monomer 1 2 3 4 5` / `scripts/run_replicates.py tetramer 1 2 3 4 5`, which wrap:

vina.exe --config monomer_vina_config.txt --out monomer_seed{1..5}_out.pdbqt --seed {1..5} > monomer_seed{1..5}_log.txt
vina.exe --config tetramer_vina_config.txt --out tetramer_seed{1..5}_out.pdbqt --seed {1..5} > tetramer_seed{1..5}_log.txt


The Mode 1 affinity from each of the 5 logs per condition was used to compute a mean ± SD (`results/tables/monomer_replicate_summary.csv`, `results/tables/tetramer_replicate_summary.csv`).

## 6. Pose extraction and geometric analysis

Multi-pose output files were split into individual models:

vina_split.exe --input monomer_out.pdbqt --ligand monomer_out
vina_split.exe --input tetramer_out.pdbqt --ligand tetramer_out


> **Note:** this splitting step is currently manual and not yet wrapped in a repo script.

**Catalytic-geometry check.** Vina's scoring function has no explicit term for reaction-competent geometry — it is a general empirical estimate of binding-favorable contacts, not a model of the hydrolysis mechanism. Each candidate pose was therefore checked directly for proximity between Thr-267's nucleophilic oxygen (OG1) and the ligand's hydrolyzable carbonyl carbon (the electrophilic center attacked during amide-bond hydrolysis):


**Note on ligand atom selection:** MGLTools' ligand PDBQT preparation assigns generic, non-unique atom names (e.g., multiple atoms all named `C`), so selecting the hydrolyzable carbonyl carbon by name alone is ambiguous and can inadvertently select the entire ligand. The carbonyl carbon was instead identified by clicking the atom in PyMOL and reading its unique atom index. After selecting the entire ligand on PyMol, run:

```python
iterate sele, print(index, name, resn, resi)
```
and selecting by that index specifically:

```python
select carbonylC, <ligand_pose_object> and index 3
distance catalytic_dist, chain A and resi 267 and name OG1, carbonylC
```

A distance in the ~2.5–3.5 Å range was taken as indicative of a plausible nucleophilic-attack geometry, consistent with typical enzyme active-site distances.

**Inter-chain contact checks (tetramer only).** To determine whether chains B/C/D contribute structurally to chain A's active site, the residue shell around Thr-267 was inspected at increasing radii:

```python
# PyMOL
select pocket_A, byres ((chain A and resi 267) around 8)
iterate pocket_A and name CA, print(chain, resi, resn)
```

No residues from chains B, C, or D appeared even at an 8 Å cutoff. To test whether the extra chains nonetheless fell within Vina's 25 Å search box (independent of direct pocket contact), atom counts were taken at the box's approximate half-width:

```python
# PyMOL
select box_shell, (chain B+C+D) within 13 of (chain A and resi 267 and name OG1)
print(cmd.count_atoms("box_shell"))
```

and, per pose, direct ligand–chain contact at Vina's approximate interaction cutoff:

```python
# PyMOL
select contacts, (chain B+C+D) within 8 of <ligand_pose_object>
print(cmd.count_atoms("contacts"))
```

## 7. Summary of what each check tests

| Check | Question answered |
|---|---|
| OG1–carbonyl C distance | Is this pose positioned for the actual hydrolysis chemistry? |
| Residue shell around Thr-267 (4–8 Å) | Does the tetramer structurally alter the active-site pocket itself? |
| Atom count within 13 Å of OG1 | Are chains B/C/D physically present inside the search box at all? |
| Atom count within 8 Å of each ligand pose | Does this specific pose make real contact with chains B/C/D? |
| Replicate mean ± SD (n=5) | Is an observed score difference between conditions reproducible, or within normal run-to-run noise? |

Full results and their interpretation are presented in the [main README](../README.md#results).
